# Raw research 4: client-only sharing loops (Haiku subagent, 2026-10-22)

Mostly press summaries, few postmortems.

Ideas: spoiler-free result card (Wordle grid: brag without spoiling; glyph grid of plots, "Day N"); date-hashed daily garden (Wordle, Balatro daily, Spelunky daily); seed code in URL fragment (#seed=) never query string; "First on this device" discovery stamp (Infinite Craft's First Discovery, but never claim global firsts); still card via canvas.toBlob and 3 s MediaRecorder clip on tap; near-miss and failure highlights (Suika clips); instant first action / pre-seeded starter plot; idle growth + rotating shop (hash of date-hour) as the return reason; deep links #mutation=<id>; honest odds from the real table ("1 in N plantings"); one-screen toy, one-line copy; copy-friendly stats line.
Avoid: fake global stats or leaderboards, forced sharing, share popups on load, guilt streaks/notifications, fake scarcity timers.
