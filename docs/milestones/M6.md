# M6: Mutation Laboratory

**Owner change (2026-10-23):** Brief section 14 assigns the laboratory to M4. This approved plan places it after M5, so the garden economy, automations and mutation set are established first.

**Objective:** Add a tactile, optional specimen-merging system without making ordinary gardening depend on it.

## Scope

- Separate laboratory scene beside the island, specimen tray and capped Rapier interactions.
- Deterministic recipes, merge chains, invalid-pair feedback and laboratory seeds Prism Fig and Sunburst.
- Lift the `src/lab` ESLint block only with an ADR; simulation rules remain in `src/sim`.

Design: [../design.md](../design.md) section 8. Motion: [../art/motion.md](../art/motion.md) 4.10.

## Slices

### S1 — Lab scene and physics
- Authored glass jar, tray, touch drag/drop and pooled/capped bodies.
- **Done when:** items move reliably on touch and no physics result can change rewards.

### S2 — Recipes and chains
- Add deterministic recipe table, chain reactions and invalid-pair feedback.
- **Done when:** same specimens always produce same result; invalid pairs return safely to the tray.

### S3 — Lab species and acceptance
- Add Prism Fig and Sunburst, seeds, models and journal entries; run milestone critique.
- **Done when:** all lab acceptance criteria pass and actionable critique findings are resolved.

## Acceptance criteria

- [ ] Merging rules are deterministic.
- [ ] Physics does not affect reward correctness.
- [ ] Drag-and-drop works reliably on touchscreens.
- [ ] Invalid combinations produce understandable feedback.
- [ ] Laboratory activity does not corrupt garden state.
- [ ] CI green with no retries.
