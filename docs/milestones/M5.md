# M5: Polish and sharing

From the brief.

**Objective.** Make the game appealing to share and return to.

## Scope

- Improved visual effects.
- Shareable mutation cards.
- Garden screenshots.
- Optional daily challenges.
- Accessibility improvements.
- Performance optimisation.
- Onboarding refinement.


Design: [../design.md](../design.md). Motion: [../art/motion.md](../art/motion.md). Work in slices, one PR each ([ADR 0009](../decisions/0009-authored-models-and-slices.md)).

## Slices

- Research additions ([design](../design.md) 11): date-hashed daily garden, `#seed=` links, spoiler-free share card, 3 s reveal clip on tap.

### S1 — Cards and photos
- Discovery cards (seed-packet print, render, rarity stamp) shared through the Web Share API with a PNG download fallback. Garden photo mode with a slow orbit and no UI.

### S2 — Daily challenge
- Date-hashed shared challenge with no server; local best score.

### S3 — Accessibility, performance and onboarding
- Colour-blind-safe mutation cues, text scale, haptics toggle; low-tier effects; device performance pass; final onboarding tune from playtests.

## Acceptance criteria

- [ ] Screenshots can be exported on supported browsers.
- [ ] Core gameplay remains usable without an account.
- [ ] Reduced-motion settings work.
- [ ] Mobile performance meets established targets.
- [ ] New players understand the game without a lengthy tutorial.
