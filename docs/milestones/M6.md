## Slices

### S1 — Lab scene and physics
- Authored glass jar, tray, touch drag/drop and pooled/capped bodies.
- **Done when:** items move reliably on touch and no physics result can change rewards.
- **Implemented:** optional level-18 lab screen opens via dynamic import; touch pointer drags transfer crate fruit atomically. Rapier loads only on entry, uses 24 pooled bodies at a capped fixed 60 Hz and moves jar contents. Selected specimens can return to the crate without loss.
- **Status:** Implemented; touch transfer and return flows pass mobile and desktop browser checks.

### S2 — Recipes and chains
- Add deterministic recipe table, chain reactions and invalid-pair feedback.
- **Done when:** same specimens always produce same result; invalid pairs return safely to the tray.
- **Implemented:** frozen + electric yields a Prism Fig seed; Golden + Glowing yields a Sunburst seed. Touching contact groups propose one sim merge; the sim consumes only valid pairs and leaves invalid specimens available to mix or return.
- **Implemented:** Prism Fig + Golden chains into Sunburst within the same sim command; duplicate contacts cannot award another packet.
- **Status:** Implemented; deterministic recipes, chains, duplicate contacts and invalid-pair recovery pass sim tests.

### S3 — Lab species and acceptance
- Add Prism Fig and Sunburst, seeds, models and journal entries; run milestone critique.
- **Done when:** all lab acceptance criteria pass and actionable critique findings are resolved.
- **Implemented:** both species grow from earned lab packets, persist in schema 11 saves, appear in the journal and use distinct palette ramps and silhouettes. Discovered recipes persist in the journal. `build_lab.py` creates optional plant models; missing rebuilt assets fall back to existing authored plants.
- **Status:** Implemented; final browser proof and both critiques approved.
