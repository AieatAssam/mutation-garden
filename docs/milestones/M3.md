# M3: Progression and economy

> The objective and scope below are provisional: the start of the brief's Milestone 3 is missing. The acceptance criteria marked "brief" are verbatim from it.

**Objective.** Give players meaningful choices about what to buy next, and make progress predictable and persistent, including while away.

## Scope

- Coins unlock new seeds, more plots, tools (watering can, fertiliser) and visible garden improvements (brief section 2, Upgrade).
- Offline growth via closed-form catch-up, as in docs/architecture.md.
- Economy data tables and automated economy simulations in Vitest.
- A clear next goal is always visible (brief success criterion 7).

## Acceptance criteria

- [ ] Players have meaningful upgrade choices. (brief)
- [ ] Progression does not stall unexpectedly. (brief)
- [ ] Economy values are validated through automated simulations. (brief)
- [ ] Offline growth cannot generate invalid or duplicated rewards. (brief)
- [ ] A 20-minute play session provides several meaningful milestones. (brief)
- [ ] Upgrades have a visible effect on the garden, not just numbers.
- [ ] `catchUp` is idempotent across reloads and additive across split intervals (property tests).
- [ ] CI green with no retries.
