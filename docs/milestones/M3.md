# M3: Progression

**Objective (brief):** Sustain interest beyond the first session.

## Scope (brief)

- Seed shop.
- Garden expansion.
- Basic upgrades.
- Garden levels.
- Objectives and achievements.
- Economy balancing.
- Offline growth.

## Details from the rest of the brief

- **One currency, Coins (section 7).** No second currency in the initial release.
- **Progression categories (section 7):** seeds, plots, tools (watering, harvesting, garden management), discovery, garden level.
- **Watering (section 4):** a limited, meaningful boost, never required tapping.
- **Pacing targets (section 7):** first meaningful upgrade within 2 minutes, first mutation within 5, new species or expansion within 10, a basic strategy within 20. Validate with the economy simulations and playtests.
- **Expansion (section 3):** more plots and decorative areas on the same island scene, with automatic camera framing; the island should look more impressive as it grows.
- **Offline growth (sections 4, 13):** real timestamps, reasonable caps, safe handling of clock changes, a short "while you were away" summary.
- **Top bar (section 8):** garden level and current objective fill the slots left in M1.

## Acceptance criteria

- [ ] Players have meaningful upgrade choices. (brief)
- [ ] Progression does not stall unexpectedly. (brief)
- [ ] Economy values are validated through automated simulations. (brief)
- [ ] Offline growth cannot generate invalid or duplicated rewards. (brief)
- [ ] A 20-minute play session provides several meaningful milestones. (brief)
- [ ] Upgrades have a visible effect on the garden, not just numbers.
- [ ] Offline results are the same however the time away is split up, and reloading never adds rewards (property tests).
- [ ] CI green with no retries.
